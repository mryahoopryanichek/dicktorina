# CLAUDE.md — Dикторина

Отвечать по-русски.

## Что это и зачем

Проверка спроса до разработки сервиса. Готовую игру — квиз для компании — режем на короткие вертикальные ролики, выкладываем в TikTok, YouTube Shorts и Instagram Reels, из профилей ведём людей на лендинг, где они записываются через Telegram-бота.

- **Порог:** 1000 записей за 4 недели. Выкладка каждый день, 2–3 ролика в день. Наберётся — делаем сервис (репо `E:\Dev\newQuiz`), нет — не делаем.
- **Денег 0:** только бесплатные инструменты и хостинг.
- **Аудитория:** русскоязычные в России, Сербии, Грузии. Ролики и лендинг — на русском.

## Как работать с решающим

- Решает владелец проекта. Решает по примерам: ролик, кадр, страница — а не по описанию.
- Вопросы — в чате, все сразу, с номерами 1, 2, 3…; у каждого — суть и варианты с ценой, рекомендуемый первым. `AskUserQuestion` не использовать.
- От чего отказался — не переспрашивать. Что знает и принял (некликабельные ссылки, страйки за музыку) — не напоминать.
- Ролик перед показом — посмотреть самому: кадры в лист (команда ниже).

Призыв — **стрелкой на профиль, не кнопкой**, «ссылка в профиле» — ниже, у острия; выравнивание **левое**. Сделано: после пыли линия ровно едет вправо всё время голоса — первую половину видна D, потом ~22 % времени весь экран из `=`, в конце въезжает 8; скорость и число `=` считаются от длины голоса (`DRIFT` в `Intro.tsx`); первая строка вопроса — шириной в слово «Dикторина»; строки появляются под свои слова в голосе; стрелка-росчерк вниз слева — на ник автора (внизу слева на всех трёх площадках). Длина ≈ 5,5 с: 0,15 + голос ≤ 4,9 + 0,5. Текст — выше нижних ~20 % и левее правых кнопок площадок. Код — `src/outro/Outro.tsx` |

## Команды

Оболочка — Git Bash.

```bash
npm ci
npx tsc --noEmit                                     # типы
npm run studio                                       # ролики в браузере
npm run render:intro                                 # заставка → out/intro.mp4 (палитра emerald)
npm run render:outro                                 # концовка → out/outro.mp4 (emerald, голос andrew)
npx remotion render src/index.ts Outro out/outro-sunset.mp4 --props='{"palette":"sunset","voice":"remy"}'
PYTHONPATH=<tmp>/pylib PYTHONIOENCODING=utf-8 python tools/voice.py   # голоса заново: текст, голоса, 4,9 с — в начале файла
npx remotion render src/index.ts Avatars out/profile/avatars --sequence --image-format=png   # аватары, PNG
npx remotion render src/index.ts Banners out/profile/banners --sequence --image-format=png   # шапки YouTube, PNG
npx remotion render src/index.ts Palettes out/check/palettes.mp4   # 12 кадров, потом в лист:
ffmpeg -y -v error -i out/check/palettes.mp4 -vf "scale=300:533,tile=6x2:padding=6:color=0x222222" -frames:v 1 out/check/palettes-sheet.png
```

Бот — в `bot/`, свои пакеты (`cd bot && npm ci`):

```bash
npm run typecheck                    # wrangler types + tsc
npm run db:local && npm run dev      # локально: база на диске, секреты-заглушки — bot/.dev.vars
npx wrangler login                   # один раз: окно браузера, решающий жмёт Allow
npx wrangler d1 create dicktorina    # один раз: database_id → bot/wrangler.jsonc
npm run db:remote && npm run deploy  # схема базы и выкладка; адрес воркера → .env как WEBHOOK_URL
npm run setup                        # секреты воркера из .env, webhook, описание, меню
```

- Локальная проверка: POST на `localhost:8787/webhook` с заголовком `X-Telegram-Bot-Api-Secret-Token: local`. Кириллицу в теле — из файла (`--data-binary @file`): curl в Windows портит её в аргументах.
- `wrangler deploy` из России иногда падает с `fetch failed` — повторить. Новый адрес `*.workers.dev` Telegram видел с ошибкой SSL ~15 минут, пока расходился сертификат; потом доставил всё, что ждало.
- До `setWebhook` бот отдаёт сообщения через `getUpdates` — так узнать id решающего для `ADMIN_IDS`: он жмёт «Старт», читаем `getUpdates`.

- **Remotion** — ролик как React-компонент, кадр зависит только от времени (`useCurrentFrame`), случайность — только `random(seed)` из `remotion`. Версии пакетов — вышедшие не меньше 2 недель назад (сейчас 4.0.538), все `@remotion/*` одной версии.
- **`<Freeze>` в 4.0.538 застывает не на том кадре.** Чтобы показать момент N, сдвигать начало: `<Sequence from={frame - N}>`.
- **ffmpeg** 9.0.2 поставлен через winget; если не в PATH — `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_Microsoft.Winget.Source_8wekyb3d8bbwe\ffmpeg-9.0.2-full_build\bin\`.
- **Репо публичный:** личного решающего — имени, путей с именем пользователя, основного аккаунта — в файлах репо не писать.
- **Проверка ролика глазами** — кадры в один лист:
  ```bash
  ffmpeg -y -v error -i out/intro.mp4 -vf "select='eq(n\,12)+eq(n\,60)+eq(n\,108)',scale=270:480,tile=3x1" -frames:v 1 -fps_mode vfr out/check/strip.png
  ```
- Python: кириллица в выводе — `PYTHONIOENCODING=utf-8`, файлы — `encoding="utf-8"`; Pillow стоит. Временные скрипты — во временной папке сессии, не в репо.
- **Голос `edge-tts`** 7.3.1 — ставить во временную папку сессии: `python -m pip install --target <tmp>/pylib edge-tts==7.3.1`. Многоязычные голоса (`en-US-AndrewMultilingualNeural` и др.) читают русский текст — список: `python -m edge_tts --list-voices | grep Multilingual`. Сервис иногда не отдаёт звук (`NoAudioReceived`) — `tools/voice.py` повторяет. Паузы до 1 с между предложениями он режет сам; фильтр ffmpeg `silenceremove` сжимает плохо.
- Пуш: `git push` — `main` отправлен 2026-11-07, вход GitHub сохранён.
- **`gh` на этом компьютере залогинен в основной аккаунт решающего — для этого репо не использовать.** Настройки репо (GitHub Pages и т. п.) решающий делает сам в браузере под `mryahoopryanichek`.
