# CLAUDE.md — Dикторина

Отвечать по-русски.

## Что это и зачем

Проверка спроса до разработки сервиса. Готовую игру — квиз для компании — режем на короткие вертикальные ролики, выкладываем в TikTok, YouTube Shorts и Instagram Reels, из профилей ведём людей на лендинг, где они записываются через Telegram-бота.

- **Порог:** 1000 записей за 4 недели. Выкладка каждый день, 2–3 ролика в день. Наберётся — делаем сервис (репо `E:\Dev\newQuiz`), нет — не делаем.
- **Денег 0:** только бесплатные инструменты и хостинг.
- **Аудитория:** русскоязычные в России, Сербии, Грузии. Ролики и лендинг — на русском.

## Как работать с решающим

- Решает владелец проекта. Решает по примерам: ролик, кадр, страница — а не по описанию.
- Вопросы — в чате, все сразу, с номерами 1, 2, 3…; у каждого — суть и варианты с ценой, рекомендуемый первым. `AskUserQuestion` не использовать.
- От чего отказался — не переспрашивать. Что знает и принял (некликабельные ссылки, страйки за музыку) — не напоминать.
- Ролик перед показом — посмотреть самому: кадры в лист (команда ниже).

| Заставка | **в конце** каждого ролика, 2,5 с: слово проявляется → «икторина» рассыпается пылью, как после щелчка Таноса, к 1 с букв нет → D стоит на месте, к ней слева выезжает `=====` → всё уезжает вправо, в хвосте 8 (`8=====D`). Код — `src/intro/Intro.tsx` |
| Концовка ролика | **4 с**, заказ решающего: заставка вверху, внизу призыв «если хотите, чтобы вышла полная игра, — регистрируйтесь, ссылка в профиле», мерцает или кнопкой. ## Открытые вопросы

- **Откуда решающий выкладывает.** Из России TikTok не даёт загружать ролики: нужен VPN другой страны и при регистрации, и при каждой выкладке.
- **12 палитр, светлая середина, крупные искры** — сделано и показано листом 2026-11-07, оценки нет.
- **«Проговорить» текст концовки:** только текст на экране, голос (бесплатно — `edge-tts`) или голос решающего — не решено. Образец со Светланой — `out/outro-emerald-voice.mp4`, речь 0,2–3,8 с. Мужской `ru-RU-DmitryNeural` 2026-11-07 не отдавал звук ни на одной фразе, кроме самой первой «Привет».
- **Хостинг бота:** предложен Cloudflare Workers + D1 (бесплатно, круглосуточно) — не подтверждён. Токен бота — только в `.env` (`BOT_TOKEN=…`), не в чат и не в git.

## Команды

Оболочка — Git Bash.

```bash
npm ci
npx tsc --noEmit                                     # типы
npm run studio                                       # ролики в браузере
npm run render:intro                                 # заставка → out/intro.mp4 (палитра emerald)
npm run render:outro                                 # концовка → out/outro.mp4 (палитра emerald)
npx remotion render src/index.ts Outro out/outro-sunset.mp4 --props='{"palette":"sunset"}'
npx remotion render src/index.ts Palettes out/check/palettes.mp4   # 12 кадров, потом в лист:
ffmpeg -y -v error -i out/check/palettes.mp4 -vf "scale=300:533,tile=6x2:padding=6:color=0x222222" -frames:v 1 out/check/palettes-sheet.png
```

- **Remotion** — ролик как React-компонент, кадр зависит только от времени (`useCurrentFrame`), случайность — только `random(seed)` из `remotion`. Версии пакетов — вышедшие не меньше 2 недель назад (сейчас 4.0.538), все `@remotion/*` одной версии.
- **`<Freeze>` в 4.0.538 застывает не на том кадре.** Чтобы показать момент N, сдвигать начало: `<Sequence from={frame - N}>`.
- **ffmpeg** 9.0.2 поставлен через winget; если не в PATH — `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_Microsoft.Winget.Source_8wekyb3d8bbwe\ffmpeg-9.0.2-full_build\bin\`.
- **Репо публичный:** личного решающего — имени, путей с именем пользователя, основного аккаунта — в файлах репо не писать.
- **Проверка ролика глазами** — кадры в один лист:
  ```bash
  ffmpeg -y -v error -i out/intro.mp4 -vf "select='eq(n\,12)+eq(n\,60)+eq(n\,108)',scale=270:480,tile=3x1" -frames:v 1 -fps_mode vfr out/check/strip.png
  ```
- Python: кириллица в выводе — `PYTHONIOENCODING=utf-8`, файлы — `encoding="utf-8"`; Pillow стоит. Временные скрипты — во временной папке сессии, не в репо.
- **Голос `edge-tts`** 7.3.1 — ставить во временную папку сессии: `python -m pip install --target <tmp>/pylib edge-tts==7.3.1`, запуск `PYTHONPATH=<tmp>/pylib python -m edge_tts --voice ru-RU-SvetlanaNeural --rate=+8% --text "…" --write-media v.mp3`. Между предложениями он ставит паузы по 1 с — резать ffmpeg (`silencedetect`, потом `atrim` + `concat`).
- Пуш: `git push` — при первом входе откроется окно GitHub, входит решающий под `mryahoopryanichek`.
