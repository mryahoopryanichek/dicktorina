# Dикторина

Ролики, лендинг и Telegram-бот для квиза Dикторина.

## Ролики

Ролики собираются из кода на [Remotion](https://www.remotion.dev/): каждый ролик — React-компонент, кадр зависит только от времени.

```bash
npm ci
npm run studio        # смотреть и крутить ролики в браузере
npm run render:intro  # заставка → out/intro.mp4
npm run render:outro  # концовка → out/outro.mp4
```

| Что | Где |
|---|---|
| Цвета, шрифт, формат 1080×1920 | `src/brand.ts` |
| Заставка: слово, пыль, линия, 8 | `src/intro/Intro.tsx` |
| Концовка: заставка, вопрос, стрелка на ник автора | `src/outro/Outro.tsx` |
| Лист всех палитр | `src/Palettes.tsx` |
| Список роликов | `src/Root.tsx` |

## Что не в git

`materials/` — материалы и запись игры, `out/` — готовые ролики и кадры. Они лежат только на компьютере автора.
